# Mushee — new website

Single-page Mushee landing page inspired by the supplied Monolith/Stratum motion reference.

## Links

- Whitepaper: https://mushee.gitbook.io/mushee_io/
- X: https://twitter.com/mushee_io
- Repository: https://github.com/mushee-io/mushee

## Run locally

No build step is required.

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Notes

The first version keeps the reference's full-screen frame, chapter rail, decode animation, pointer parallax, responsive menu and scene cross-fades. Background media is loaded from the motion-reference source URLs so the repository stays lightweight during the first design pass.
